# Build a Number Guessing Game

FreeCodeCamp Relational Databases v9 certification project (unit 063).

- `number_guess.sql` — recreates the `number_guess` database (users, games).
- `number_guess.sh` — the guessing game: random secret 1-1000, per-user game history and best score.

Built as a fleet run in timerloggedout-spec/termux-monorepo (`cert-project.yml` run 41381256768, fileset mode):
structure verified in-run and full games driven end-to-end by a binary-search player.
